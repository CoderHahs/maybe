# Monarch Feature Parity — Overview

This document defines the features Maybe needs to reach parity with Monarch (monarch.com), a leading personal finance app. Features are organized by priority and grouped by domain.

## Feature Gap Summary

### Already in Maybe (keep and improve)

- Account aggregation (Plaid + manual)
- Net worth tracking and historical graphs
- Transaction list with categorization
- Budget tracking (categories)
- Investment/holdings tracking
- Multi-currency support
- AI chat assistant (OpenAI)
- CSV import
- Tags and rules for auto-categorization
- Family/household model with multiple users
- Transfer detection and matching
- Account types: depository, investment, crypto, property, vehicle, credit card, loan
- Data export
- Self-hosting via Docker

### Missing — High Priority

1. Recurring transactions / subscription detection
2. Cash flow forecasting and insights
3. Enhanced goal planning (savings goals, debt payoff goals, retirement)
4. Shared views with yours/mine/ours labeling
5. Credit score tracking
6. Receipt scanning with item-level categorization
7. Enhanced AI assistant (weekly summaries, trend surfacing, proactive insights)
8. Transaction review workflow (mark as reviewed)
9. Customizable dashboard widgets
10. Bill calendar with upcoming payment alerts

### Missing — Medium Priority

11. Equity/RSU/stock option tracking (vested vs unvested)
12. Retail purchase sync (Amazon/Target-style item-level splitting)
13. Saved/favorite reports
14. Flexible budget buckets (Fixed / Flex / Non-monthly)
15. Investment benchmarking (compare portfolio vs S&P 500)
16. Financial advisor/CPA collaboration access
17. Connectivity dashboard (account health status)
18. Mobile app (iOS + Android) with push notifications
19. Browser extension for retail sync

### Missing — Lower Priority

20. Notification preferences (custom alerts for spending, bills, goals)
21. PWA enhancements (offline support, home screen install)
22. Debt snowball/avalanche payoff strategies
23. Tax-related reporting and categorization
24. Property value sync (Zillow-style)
25. Crypto exchange connectivity beyond manual entry
